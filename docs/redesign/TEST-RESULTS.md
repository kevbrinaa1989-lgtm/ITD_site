# Проверка реализации «Маршрута»

11 ноября 2026. Проверялось работающее приложение из `feature/itd-superdesign-redesign`, а не интерактивный макет. Node 24.19, Chromium/Playwright в изолированном окружении. Каждый набор создаёт собственную временную SQLite, пользователей и файлы через настоящие API; продуктивная база не открывается.

## Результаты

- `npm test`: **189/189**, без пропусков и ошибок. В том числе права, CSRF, приглашения, восстановление, версии, ревизии, конфликты решений, хранение после перезапуска и полное резервирование/восстановление базы вместе с файлами.
- **9 браузерных наборов, 43 сочетания набора и ширины**. Все успешно; подробный машиночитаемый отчёт — [validation/implementation-results.json](validation/implementation-results.json).

Браузерные проверки контролируют ошибки JavaScript, горизонтальное переполнение и отсутствие внешних запросов кабинета. Внешние шрифты и логотип заменены локальными ресурсами. Изменены только селекторы старых сценариев, которым теперь требуется мобильная кнопка возврата к библиотеке; серверные проверки и ожидания сохранности данных сохранены. Учёт просмотров в тестах учитывает новый встроенный просмотр.

## Практические границы проверки

Ширины проверены в Chromium, включая touch-режим и синтетический pinch. Физические iPhone/Android и Safari отдельно не проверялись. VPS, его фактическая конфигурация, HTTPS и внешний репозиторий резервных копий в этой задаче не менялись и не проверялись. Резервирование/восстановление проверено локальными автоматическими тестами, инструкция для оператора приложена отдельно.

GitHub Actions добавлен только для тестов и артефактов; публикации, SSH, серверных секретов и миграций в workflow нет. Итоговый статус удалённого CI виден непосредственно в PR. Команды воспроизведения и установка тестового Chromium — [UPDATE-AND-ROLLBACK.md](UPDATE-AND-ROLLBACK.md).
