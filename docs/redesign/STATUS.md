## Следующий этап после снятия блокировки

1. Открыть текущий itdstudio.ru, зафиксировать реальные фирменные цвета, шрифты, логотип и композиционные принципы.
2. Завершить авторизацию Superdesign и создать проект с безопасными вымышленными данными.
3. Спроектировать три направления: рабочий экран «список + выбранный материал», редакционный обзор проекта, компактный маршрут по этапам. Это направления исследования, а не готовые визуальные макеты.
4. Сравнить их на одном сценарии: найти актуальную версию, открыть файл, оставить замечание, подтвердить решение. Отдельно оценить 360/390 px.
5. Для выбранной концепции подготовить экраны администратора, клиента, проекта, материала с версиями и обсуждением, клиентов/задач, мобильные варианты и состояния без данных/ошибок.
6. Показать пользователю настоящие ссылки canvas/preview, объяснить изменения и дождаться утверждения.

Реализация и PR — после утверждения дизайна. Изменение структуры базы допустимо только при доказанной необходимости, отдельной оценке совместимости и безопасной миграции. Публикация на VPS требует отдельного разрешения.
