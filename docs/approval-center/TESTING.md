## Воспроизведение

Node.js 24.13–24.x; `npm ci`, затем `npm test`. Playwright установлен отдельно от производственных зависимостей. `ITD_PLAYWRIGHT_MODULE` может указывать на его `index.mjs`; `ITD_CHROMIUM` — на установленный Chrome/Edge/Chromium.

```sh
ITD_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs ITD_CHROMIUM=/path/to/chrome node tests/browser-approval-center.mjs
ITD_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs ITD_CHROMIUM=/path/to/chrome node tests/browser-approval-pdf.mjs
ITD_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs ITD_BROWSER=webkit ITD_NO_SCREENSHOTS=1 node tests/browser-approval-center.mjs
```

`ITD_SCREENSHOT_DIR` задаёт папку снимков; `ITD_BROWSER_IMAGE` — необязательную локальную PNG-иллюстрацию (по умолчанию используются существующие тестовые пиксели из репозитория); `ITD_MATERIAL_COUNT=100` включает браузерную проверку большого комплекта. Установленные браузеры и библиотеки машины не включены в PR.
