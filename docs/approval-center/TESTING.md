## Воспроизведение

Node.js 24.13–24.x; `npm ci`, затем `npm test`. Playwright установлен отдельно от производственных зависимостей. `ITD_PLAYWRIGHT_MODULE` может указывать на его `index.mjs`; `ITD_CHROMIUM` — на установленный Chrome/Edge/Chromium.

```sh
ITD_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs ITD_CHROMIUM=/path/to/chrome node tests/browser-approval-center.mjs
ITD_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs ITD_CHROMIUM=/path/to/chrome node tests/browser-approval-pdf.mjs
ITD_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs ITD_BROWSER=webkit ITD_NO_SCREENSHOTS=1 node tests/browser-approval-center.mjs
```

`ITD_SCREENSHOT_DIR` задаёт папку снимков; `ITD_BROWSER_IMAGE` — необязательную локальную PNG-иллюстрацию (по умолчанию используются существующие тестовые пиксели из репозитория); `ITD_MATERIAL_COUNT=100` включает браузерную проверку большого комплекта. Установленные браузеры и библиотеки машины не включены в PR.

Подключите телефон к той же сети Wi-Fi, что и компьютер с запущенной демоверсией. Откройте адрес кабинета из окна запуска или из сообщения о приёмке. Телефону нужен доступ к компьютеру внутри сети по TCP на порт из адреса запуска. Для текущей приёмки используется порт 4176. Гостевая сеть с изоляцией устройств такой доступ блокирует.

1. Войдите как клиент. Откройте «Мои проекты» → «Балтика» → «Согласования» и выберите этап из таблицы. В нём два PDF. Для полного цикла с 40 файлами есть отдельный этап «Обмеры».
2. Откройте «Общий план». Проверьте очередь «Материалы», полноэкранный режим и увеличение двумя пальцами. Нажмите «Согласовать и далее». После сохранения откроется «План перегородок».
3. На первом листе нажмите «Согласовать и далее». Появится сообщение о просмотре одного листа из двух. Откройте второй лист и нажмите «Нужны правки». Введите замечание, поставьте отметку на листе и нажмите «Подготовить и далее». Дождитесь «Сохранено», перезагрузите страницу, откройте тот же этап и сводку «К отправке · 2». Проверьте текст и отметку на втором листе.
4. Проверьте состав пакета и нажмите «Подтверждаю отправку». Через «•••» → «История и ведомости» скачайте первую ведомость. В другом браузере войдите как дизайнер. На том же этапе выберите возвращённый материал и откройте «Работа с материалом» → «Загрузить исправленную версию». Приложите трёхстраничный образец из окна стенда и заполните отчёт по замечанию.
5. В клиентском окне выберите «•••» → «Обновить данные». Сравните v1 и v2 через «Было / Стало». Отметка на втором листе относится к v1. Подтвердите исправление через «Замечания и история», просмотрите три листа v2, подготовьте решение и отправьте второй пакет. Проверьте вторую ведомость и отдельно примите этап через «Готовность этапа».

Для каждого из трёх браузеров запишите модель устройства, версии ОС и браузера и результат шагов 1–5. При сбое укажите последний шаг и приложите снимок с сообщением. Если доступна удалённая консоль устройства, сохраните относящиеся к этому шагу ошибки и статусы запросов без данных входа. Во время подготовки стенда вход, панели и PDF проверены с компьютера по адресу Wi-Fi. Физические устройства и подключённый сервис с ними в этой сессии были недоступны.
