# ITD Studio — Tilda + анкета

Начните с [НАЧНИТЕ-ЗДЕСЬ.md](НАЧНИТЕ-ЗДЕСЬ.md).

Это доработка предоставленного архива ITD_Studio_INSIDE_with_Anketa.zip. Дизайн и материалы сохранены, обработка форм заменена на автоматическую отправку через отдельный серверный обработчик в Make.

В комплекте есть локальная статическая версия (index.html, anketa.html), сборщик вставок T123 и серверная часть. Реальные адреса размещения вспомогательных файлов и обработчика ещё не настроены; сценарий Make не подключён. Не считайте шаблоны с .invalid готовыми публичными страницами.

- Подготовка Tilda: tilda/README.md
- Серверная часть: integration/README.md
- Настройка Make: integration/MAKE-SETUP.md
- Проверки: VERIFICATION.md

Для полной схемы требуется HTTPS для сайта, вспомогательных файлов и обработчика. Адрес Make хранится только в конфигурации сервера. Пароли, ключи и адрес вебхука не включены в этот комплект.
