# Правила работы с проектом

Следуйте четырём принципам [Karpathy Guidelines](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/skills/karpathy-guidelines/SKILL.md):

1. Сначала обдумайте решение: явно обозначайте предположения и существенные компромиссы; уточняйте то, что блокирует работу.
2. Выбирайте простоту: минимальный код для поставленной задачи, без незапрошенных функций и абстракций.
3. Делайте точечные изменения: меняйте только необходимое, соблюдайте существующий стиль и сохраняйте чужие изменения.
4. Работайте по проверяемым целям: определите критерии успеха, проверьте результат и исправьте обнаруженные недостатки до приёмки.

Используйте существующую рабочую копию: облачные задачи уже изолированы. Не создавайте Git worktree без явного запроса пользователя.

Проверки кабинета: `node --test server.test.mjs`, `node --check server.mjs`, `node --check cabinet.js`. Не отправляйте тестовые заявки в Make.com и не используйте настоящие документы клиентов в автоматических тестах. Базу, загруженные документы и пароли не добавляйте в Git.
