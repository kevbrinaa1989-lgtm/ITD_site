# ITD Studio project file library — selected Route evolution
Design one unified project library, within the approved light architectural Route shell. No alternatives. Materials are stage-grouped compact image cards (3-4 desktop columns); documents are restrained horizontal rows (format icon, human title, kind/number/date, stage, size, Open and Download). Top segmented All / Materials / Documents, search, secondary collapsible filters (stage/type), sort recent/name/document date. One entry per ordinary file or review material, with historical versions reachable in its existing detail. No duplicated gallery hero plus repeated cards. Album is an optional presentation mode with a back action. Review remains a functional selected-version workspace with decisions/comments, with return to filtered library. Admin uploads through compact dialog, existing multiple-file queue/recipient protection/document metadata/idempotent retry. Client gets no upload/delete controls. Mobile filters wrap, inputs >=16px, targets >=44px, document actions below metadata, two comfortable image columns or one at narrow widths. Upload dialog scrolls internally. No production data; examples fictional, public portfolio imagery only. Keep existing logo/assets. Implement with existing vanilla JS and APIs, no database changes. Prefer Manrope UI and Prata only page title, cream/ink/bronze tokens. Render an actionable responsive page and document detail, no decorative CRM widgets.
