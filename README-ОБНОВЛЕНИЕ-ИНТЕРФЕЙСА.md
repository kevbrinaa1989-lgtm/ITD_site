# Обновление кабинета ITD Studio

## Как установить обновление на Windows

1. Остановите приложение: в окне, открытом через **ЗАПУСТИТЬ.cmd**, нажмите **Ctrl+C**. Остановите также другие запущенные копии.
2. В прежней папке приложения откройте **РЕЗЕРВНАЯ-КОПИЯ.cmd**. Дождитесь сообщения об успешном создании копии и сохраните её адрес. Скопируйте всю папку копии с датой на отдельный диск. В ней должны быть `itd.sqlite`, папка `files` и `backup.json`. Если копирование завершилось ошибкой, сначала устраните её.
3. Распакуйте ZIP обновления в **новую отдельную папку**. Прежнюю папку приложения и папку данных сохраните.
4. Под тем же пользователем Windows откройте **ЗАПУСТИТЬ.cmd** из новой папки, где находится `server.mjs`. Настройки автоматически укажут на прежние данные. **ПЕРВЫЙ-ЗАПУСК.cmd не запускайте**: он предназначен для первоначальной настройки. Подключать другую папку данных и менять `storage.json` для этого обновления не нужно.
5. Откройте адрес, указанный в окне запуска, и войдите с прежними данными. Проверьте свои проекты, материалы, документы и согласования. Не запускайте одновременно старую и новую версии.

На компьютере по-прежнему нужен Node.js 24, не ниже 24.13. Если запуск сообщает об ошибке, сохраните её текст и остановитесь: не удаляйте данные, настройки или копии и не пытайтесь выполнить первоначальную настройку заново.

## Что происходит с данными

При необходимости приложение обновляет структуру базы: разрешает проекту существовать без клиента и добавляет необязательные описание проекта и телефон пользователя. Существующие проекты сохраняют назначенных клиентов; пароли и файлы не заменяются.

Перед изменением существующей базы создаётся и проверяется снимок `migration-snapshots/snapshot-…/itd.sqlite` внутри папки данных. При ошибке изменения базы откатываются, а снимок сохраняется. **Этот снимок содержит только базу**: он не заменяет полную резервную копию с документами из шага 2. Не заменяйте им рабочую базу вручную. Обычные резервные копии включают обновлённую базу и файлы; порядок проверки и восстановления описан в [ДАННЫЕ-И-КОПИИ.md](ДАННЫЕ-И-КОПИИ.md).

## Как пользоваться обновлением

- **Проект без клиента.** На главной администратора или в разделе «Проекты» нажмите «Создать проект». Укажите название; клиент и описание необязательны. Выберите «Без клиента — назначить позже». Такой проект и его файлы доступны только администратору.
- **Назначение клиента.** Откройте проект и нажмите «Назначить клиента». Проверьте имя и email: после подтверждения клиент получит доступ ко всем уже добавленным материалам и документам. Если назначение изменилось во время подготовки загрузки, подготовьте файл заново после проверки получателя.
- **Этапы.** При создании доступны семь стандартных этапов; создаются только отмеченные. Старые этапы не переименовываются и не объединяются. «Техническое описание дизайн-проекта» и «Спецификация отделочных материалов, мебели и оборудования» — названия шаблонов для новых проектов.
- **Профиль.** Клиент меняет своё имя и необязательный телефон в «Мой профиль». Администратор редактирует эти данные в карточке клиента. Email через эти формы не изменяется.

Для работы с материалами открывайте нужный проект и этап. Перед каждой загрузкой проверяйте указанные проект, клиента и этап.
