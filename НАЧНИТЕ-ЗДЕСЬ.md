# Как попробовать кабинет

1. Установите **Node.js 24 LTS** с https://nodejs.org/.
2. Распакуйте скачанный ZIP целиком.
3. Откройте терминал в папке, где находятся `package.json` и `server.mjs`.

## Windows — PowerShell

Для первого запуска с вашей учётной записью администратора:

```powershell
$env:ITD_DATA_DIR = Join-Path $PWD ".itd-data"
$env:ITD_ADMIN_EMAIL = Read-Host "Ваш email администратора"
$secret = Read-Host "Новый пароль (не менее 12 символов)" -AsSecureString
$env:ITD_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new("", $secret).Password
npm start
```

## macOS / Linux — Bash

```bash
export ITD_DATA_DIR="$PWD/.itd-data"
read -rp 'Ваш email администратора: ' ITD_ADMIN_EMAIL
read -rsp 'Новый пароль (не менее 12 символов): ' ITD_ADMIN_PASSWORD
printf '\n'
export ITD_ADMIN_EMAIL ITD_ADMIN_PASSWORD
npm start
```

## После запуска

Введите в адресной строке браузера `http://127.0.0.1:8000/cabinet` и войдите с указанными email и паролем. Появится административная панель. Для проверки клиента откройте отдельное приватное окно браузера и зарегистрируйте другой email. В админке нажмите «Обновить», создайте проект и назначьте этого клиента.

Сервер работает, пока открыт терминал. Остановка — Ctrl+C. Открывать `cabinet.html` двойным щелчком не нужно.

Для следующих запусков достаточно задать `ITD_DATA_DIR` той же командой для вашей системы и выполнить `npm start`: созданные аккаунты и данные сохраняются в `.itd-data`. Не удаляйте эту папку, если нужны сохранённые проекты. Не публикуйте её и не добавляйте в Git.

Это локальная проба. Настоящие документы клиентов пока не загружайте. Для размещения в интернете нужен сервер Node.js с HTTPS и постоянным хранилищем; подробности — в README.md.
