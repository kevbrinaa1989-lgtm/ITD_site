# Запуск с прежними данными

Нужен **Node.js 24 LTS**, не ниже 24.13. Данные остаются в вашей прежней `.itd-data`. Не удаляйте её и старую папку проекта, в которой она находится.

## Один раз после обновления — Windows

1. Остановите все старые окна приложения: в каждом нажмите **Ctrl+C** и дождитесь остановки. Если Windows спросит о завершении командного файла, введите `Y` и нажмите Enter. Старые версии должны быть закрыты во время подключения и копирования.
2. Распакуйте новый ZIP **в отдельную новую папку**, не поверх прежних файлов. Откройте вложенную папку с `server.mjs`.
3. Дважды нажмите **ПОДКЛЮЧИТЬ-ДАННЫЕ.cmd**. Если расширения скрыты, название будет «ПОДКЛЮЧИТЬ-ДАННЫЕ», тип — «Командный файл Windows».
4. Вставьте полный адрес **прежней папки .itd-data**, внутри которой лежат `itd.sqlite` и `files`. Нажмите Enter. Чтобы скопировать адрес, откройте эту папку в Проводнике, нажмите **Ctrl+L**, затем **Ctrl+C**; вставьте в окно команды через **Ctrl+V**. В конце пути должно быть `.itd-data`.
5. Проверьте показанное число аккаунтов, проектов и документов. Если это ваши данные, введите **ДА** и нажмите Enter. Программа проверит данные, создаст первую резервную копию и запомнит адрес. Дождитесь **«Подключено»** и пути проверенной копии. Если числа неверные, закройте окно без подтверждения и найдите правильную папку.
6. Дважды нажмите **ЗАПУСТИТЬ.cmd**. Дождитесь «Приложение запущено». В браузере откройте `http://127.0.0.1:8000/cabinet`. Войдите с **прежними** email и паролем. Новый аккаунт не нужен.

В дальнейшем, включая перезагрузку компьютера, достаточно открыть **ЗАПУСТИТЬ.cmd**. Окно оставляйте открытым. Вводить адрес каждый раз не нужно. Автозапуск при включении Windows не настраивается. Переменная `ITD_DATA_DIR` больше не используется.

Адрес хранится в профиле пользователя Windows: `%USERPROFILE%\.itd-studio\storage.json`. Запускайте под тем же пользователем Windows. Файл содержит только путь, не сами аккаунты и документы. Не редактируйте его вручную.

## Резервная копия — после дня работы и перед обновлением

1. Остановите приложение через **Ctrl+C**, закройте старые версии.
2. Дважды нажмите **РЕЗЕРВНАЯ-КОПИЯ.cmd**.
3. Дождитесь **«Резервная копия создана и проверена»**. В окне будет полный путь. Каждая копия — отдельная папка с датой внутри `ITD-backups`, рядом с вашей `.itd-data`. Старые копии не заменяются и не удаляются. Нужно свободное место для базы и всех документов.
4. Скопируйте **всю папку с датой** на отдельный внешний диск: выделите её в Проводнике, нажмите **Ctrl+C**, откройте внешний диск, нажмите **Ctrl+V**. Копия на том же диске не спасёт при его поломке. Не публикуйте копии на GitHub и не отправляйте в чат: там личные данные и документы.
5. Снова откройте **ЗАПУСТИТЬ.cmd**.

Копия содержит `itd.sqlite`, папку `files` и `backup.json` для проверки целостности. Не изменяйте её содержимое. Первая копия создаётся автоматически при подключении, последующие запускаете вы. Автоматического расписания нет.

## Если появилась ошибка

При недоступном диске, пропавшей базе, повреждённых настройках или недостающих документах запуск останавливается с пояснением. Другую пустую базу приложение не создаёт. Проверьте подключение диска. Не удаляйте данные и настройки, не создавайте аккаунты «взамен пропавших». Сообщите помощнику текст ошибки. При прерывании копирования предыдущие копии остаются; новая неполная папка не считается готовой копией.

## Если компьютер сломался

Используйте копию с внешнего диска. Порядок проверки и восстановления **на новом компьютере**: [ДАННЫЕ-И-КОПИИ.md](ДАННЫЕ-И-КОПИИ.md). Восстановятся данные на момент создания копии.

## Что проверить самостоятельно

Войдите прежним аккаунтом, откройте знакомый проект и скачайте документ. Остановите и снова запустите приложение, затем повторите проверку после перезагрузки компьютера. Адрес данных в окне запуска должен быть одинаковым.

HTML-файл двойным щелчком не запускает кабинет: нужна работающая программа. Размещение в интернете — отдельная настройка, см. README.md.
